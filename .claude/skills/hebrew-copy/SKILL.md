# Hebrew copy — Tal Roman

## Voice
- Warm, personal, calm, confident — Tal speaks in first person ("אני", "כתבו לי", "אחזור אליכם"). Never clinical, never pushy, never cheesy.
- The subject is intimate: readers want to feel understood, not sold to. Reassure about discretion where it matters ("בדיסקרטיות מלאה").
- Minimal: one idea per line, short buttons (2–4 words). Cut adjectives before cutting meaning.
- Don't invent facts, numbers, testimonials or promises; reuse existing approved copy when it exists.

## Gender
- Default: gender-inclusive plural — "כתבו לי", "אתם", "בשבילכם", "רוצים…?" — or neutral forms ("אפשר להתחיל…", "לקבלת…"). Avoid slashes (מאשר/ת) in headlines; acceptable in legal/consent text.
- Exception: pages aimed at one gender on purpose (e.g. the "what women want" presale is addressed to men) — keep their gender.

## Typography & RTL
- **No italics in Hebrew.** Emphasis = bold or the rose/serif accent word.
- Text is stored in logical order: punctuation at the end of the sentence in the string ("…יותר." not ".…יותר"); parentheses wrap the Hebrew text normally. If punctuation shows on the wrong side, fix the content string, not with CSS.
- Mixed numbers/Latin: "‎22,000+" style counts render fine; use thin spacing around "·" separators; non-breaking space before "|" in lists so a lone pipe never wraps.
- Quotes: Hebrew gershayim (״) or "…"; abbreviations with geresh (דק׳).

## CTAs & invites
- Match the page's intent: on content pages the free guide is the main invite; on course/about pages getting in touch or the course comes first and the guide is secondary.
- Vary the gift invite wording so it fits the page ("רוצים הדרכה שמתאימה בדיוק לכם?", "להעמיק גם לבד", "להתחיל עם הדרכה במתנה") instead of repeating one phrase everywhere.
- Consent text must say exactly what people agree to; never imply marketing emails to people who didn't tick consent.

## SEO strings
- Title: "<page> — טל רומן" (≤ ~60 chars). Description: one natural sentence (≤ ~155 chars) with the main topic word, no keyword stuffing.

## Deliverable
When you write new copy, list every new string so the owner can review it.
